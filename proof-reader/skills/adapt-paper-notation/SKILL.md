# Borrow a paper’s notation

Use the paper being read as the source of every claim. Use the reference to establish how it denotes the same mathematical objects. A title, shared keyword, or identical glyph gives too little evidence for a correspondence.

For each useful change, locate the two definitions. Check the object, domain, units, indices, time convention and quantifiers. A processing *requirement* and a job’s *remaining work at time* can both look like a job size. They are interchangeable only under additional conditions, so retain their separate names. Preserve bound variables and distinguish a family from a member of the family.

Read the surrounding argument for competing uses of each proposed symbol. If the reference writes \(T\) for a time horizon and the target already uses \(T\) for a tree in the same argument, keep the target’s names there. Where different sections genuinely bind the same glyph to different objects, record the applicable parts explicitly. Leave a source-only construction in its original notation. Use a natural variant of a reference convention only if the corresponding notation is attested in the supplied reference and preserves the source distinctions.

Reconstruct each section’s mathematical argument in the selected notation. Introduce each quantity in a sentence where it earns its name. On first use of a changed quantity, briefly connect the reading symbol to the paper’s original when it helps the reader find the passage. Preserve all conditions, directions of implications, types of bound, and cases. Keep original quotations, equation numbers, theorem labels and page locators exactly as printed. Render a translated restatement as exposition.

Check the result in the other direction. Interpret its symbols using the proposed correspondence and recover the original claim. If that changes a hypothesis, captures an index or conflates two quantities, narrow the correspondence to its valid scope or keep the original symbol. Never use the reference’s assumptions, results or algorithms to fill a gap in the paper being read.
